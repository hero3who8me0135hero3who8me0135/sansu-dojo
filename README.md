# せきせんせいの算数道場（ホーム画面アプリ版）

タブレットやスマホのホーム画面から全画面で起動でき、一度開いたあとはネットなしでも使えるアプリです。

## 入っているファイル

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体 |
| manifest.webmanifest | アプリ名・アイコン・全画面表示の設定 |
| sw.js | ネットなしで動かすための仕組み（端末にファイルを保存） |
| icons/ | ホーム画面のアイコン |
| fonts/ | 文字の書体（ネットなしでも同じ見た目にするため同梱。ライセンスは OFL-*.txt） |

## 公開の手順（GitHub Pages・無料）

1. github.com にログインし、右上の「＋」→「New repository」を選ぶ。
   - Repository name：`sansu-dojo`
   - 「Public」を選ぶ（無料プランで公開するには Public が必要）
   - 「Create repository」を押す
2. 表示された画面の「uploading an existing file」を押す。
3. この README と同じフォルダにあるもの（index.html、manifest.webmanifest、sw.js、README.md、fonts フォルダ、icons フォルダ）をすべて選び、ブラウザの画面にドラッグする。
4. 下の「Commit changes」を押す。
5. 「Settings」→ 左の「Pages」→「Branch」で `main` と `/ (root)` を選び「Save」。
6. 1〜2分待つと、画面上部に公開アドレスが出る（例：`https://ユーザー名.github.io/sansu-dojo/`）。

## タブレットに入れる手順

1. タブレットの Chrome で、公開アドレスを開く。
2. 右上の「︙」→「アプリをインストール」（または「ホーム画面に追加」）を押す。
3. ホーム画面のアイコンから起動すると、全画面で開く。
4. 確認：機内モードにしてアイコンから起動し、問題が解ければ、ネットなしでも動いている。

## アプリを直したいとき

1. GitHub で index.html を新しいものに差し替える（「Add file」→「Upload files」）。
2. sw.js の 3 行目 `const VERSION = "v1";` を `"v2"` のように 1 つ上げて保存する。
3. タブレットでネットにつながった状態で 1 回起動 → 次に起動したときから新しい版になる。

## 注意

- 記録（★・判子・復習リスト）は、タブレットの中に保存されます。アプリを削除したり、Chrome のデータを消したりすると消えます。
- Claude 上で遊んだ記録は、このアプリには引き継がれません（保存場所が別のため）。
- Public のリポジトリなので、アドレスを知っていれば誰でも開けます（個人の情報は含まれていません）。
